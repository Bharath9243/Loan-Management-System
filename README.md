# Loan Management System

A Loan Management System developed using **Blazor Server**, **ASP.NET Core**, **SQL Server**, and **Dapper**. The application enables administrators to manage loan types, loan schemes, and customer loan applications, while customers can register, log in, browse loan schemes, and submit loan applications.

---

## Features

### Authentication
- Customer Registration
- Login & Logout
- Cookie Authentication
- Role-Based Authorization (Admin & Customer)

### Admin
- Dashboard
- Manage Customers
- Manage Loan Types
- Manage Loan Schemes
- View All Loan Applications
- View Application Details

### Customer
- Register
- Login
- View Loan Types
- View Loan Schemes
- Apply for Loans
- View Own Loan Applications

### Dashboard
- Total Customers
- Total Loan Applications
- Total Loan Amount
- Expected Interest
- Recent Loan Applications
- Most Applied Loan Schemes
- Recently Added Loan Schemes

4. Create the database and tables.

5. Run the project.
